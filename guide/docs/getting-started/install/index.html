설치

DMG를 받아 /Applications로 옮기면 끝입니다. 인증이나 별도 도구는 필요 없습니다.

시작하기 전에​

  • Apple Silicon Mac인지 확인합니다. Intel Mac에서는 실행되지 않습니다.
  • macOS 14 이상인지 확인합니다.

설치​

  1. 브라우저에서 릴리스 페이지를 엽니다.
  2. 최신 릴리스의 Sogon.dmg (Apple Silicon, notarized)를 받습니다.
  3. 실행 중인 Sogon이 있으면 메뉴 바 아이콘을 눌러 빠른 제어 맨 아래의 종료(⌘Q)를 누릅니다.
  4. DMG를 열고 Sogon.app을 Applications 폴더로 끌어다 놓습니다.
  5. /Applications/Sogon.app을 실행합니다.

배포본은 Developer ID 서명과 Apple 공증을 마쳤습니다. xattr로 격리 속성을 지우거나 보안 설정을 낮출 필요가 없습니다.

Homebrew로 설치​

Homebrew를 쓰신다면 한 줄입니다.

brew install --cask ddiiwoong/tap/sogon

처음에는 탭이 자동으로 추가됩니다. 위의 DMG 설치와 같은 공증된 파일을 받아 /Applications에 넣고, 체크섬을 검증합니다.

업데이트는 Sogon이 직접 받으므로(아래 참고) brew upgrade를 쓰지 않아도 됩니다. 굳이 Homebrew로 올리고 싶으면 brew upgrade --cask ddiiwoong/tap/sogon입니다.

처음 실행할 때 권한 허용​

첫 실행에서 macOS가 권한을 묻습니다. Sogon을 쓰려면 두 가지가 필요합니다.

  • 마이크 — 녹음과 받아쓰기에 씁니다.
  • 손쉬운 사용 — 커서 위치에 글자를 넣는 데 씁니다. 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 Sogon을 켭니다.

설치를 확인하는 방법​

  • 메뉴 바에 Sogon 아이콘이 생깁니다. 기본 설정에서는 Dock에도 아이콘이 있습니다.
  • 처음 실행하면 튜토리얼 창이 열립니다. 이어서 첫 실행과 권한을 따라갑니다.

안 될 때​

증상조치
"Sogon.app"을(를) 열 수 없습니다 경고공증된 빌드입니다. Finder에서 앱을 Control-클릭해 열기를 누르거나, 시스템 설정 → 개인정보 보호 및 보안에서 확인 없이 열기를 누릅니다.
받아쓰기가 커서에 안 들어감시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 Sogon이 켜져 있는지 봅니다.
메뉴 바 아이콘이 보이지 않음노치나 다른 메뉴 바 앱에 가려졌을 수 있습니다. Dock 아이콘을 누르면 설정 창이 열립니다.

업데이트는 Sogon이 스스로 받아 설치합니다. 새 판이 있으면 창이 떠서, 누르면 설치하고 앱을 다시 띄웁니다. 최신이면 아무 것도 나타나지 않습니다. 지금 바로 확인하려면 메뉴 바 빠른 제어의 업데이트를 누릅니다. 새 버전이 나온 사실은 빠른 제어와 설정 → 상태 탭에 한 줄 안내로도 붙습니다.

처음 설치처럼 DMG를 직접 받아 덮어써도 됩니다.
