단축어

계좌번호, 주소, 자기소개, 영문 템플릿처럼 매번 같은 글을 다시 치는 일을 줄입니다. 단축어는 교정을 거치지 않고 저장한 그대로 들어갑니다.

저장하기​

두 가지 방법이 있습니다.

  • 저장할 글을 선택하고 ⌃⇧C를 누른 뒤 격자에서 w(단축어로 저장)를 누릅니다. 이름을 넣고 저장합니다.
  • 설정 → 단축어에서 추가를 누르고 이름과 본문을 씁니다.

설정 → 단축어의 제목 자동 제안을 켜면 LLM이 이름을 제안합니다. 기본값은 꺼짐입니다. 켜면 글의 앞부분 500자가 고른 LLM 프로바이더로 전송됩니다.

넣기​

  1. 글을 넣을 자리에 커서를 둡니다.
  2. ⌃⇧V를 누릅니다.
  3. 이름이나 내용 일부를 입력해 거릅니다.
  4. ↑·↓로 고르고 ⏎를 누릅니다.
키동작
⏎고른 단축어를 커서에 넣습니다.
⌘1~⌘9보이는 목록의 1~9번째를 바로 넣습니다. 번호는 거른 목록을 따릅니다.
⌘⏎커서 대신 클립보드에 넣습니다. 원격 데스크톱처럼 붙여 넣기가 닿지 않는 곳에서 씁니다.
esc아무것도 넣지 않고 닫습니다.

단축어는 받아쓰기 대기열을 거치지 않으므로 회의 녹음 중에도 바로 들어갑니다. 전사 기록에는 남지 않습니다.

관리하기​

  • 설정 → 단축어 목록에서 ⇧클릭·⌘클릭으로 여러 개를 고르고 ⌫를 누르면 한 번에 지웁니다. 확인 대화상자에 지울 개수가 표시됩니다.
  • 목록 순서는 사용자가 정한 순서를 따릅니다. 자주 쓴 순으로 자동 정렬하지 않습니다.
  • 이름이 같은 단축어를 여러 개 둘 수 있습니다.
  • 단축키는 설정 → 일반 → 녹음 → 단축어 단축키에서 바꿉니다.

Sogon은 복사한 내용을 자동으로 쌓는 클립보드 기록 앱이 아닙니다. 사용자가 저장한 문구만 다룹니다.
