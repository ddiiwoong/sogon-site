AWS Transcribe로 전사

AWS Transcribe는 세션 오디오를 S3에 올려 전사하고, 단어마다 시각과 화자를 붙여 돌려줍니다. 결과는 화자 붙이기와 같은 자리에 저장되어 화자 탭, 이름 짓기, 내보내기가 그대로 동작합니다. 참석자 수를 적을 필요가 없고 최대 30명까지 구분합니다.

오디오가 계정 밖으로 나갑니다

회의 오디오 전체가 S3에 업로드되고 Transcribe·S3 요금이 발생합니다. 전사가 성공하든 실패하든 앱이 끝나면 업로드한 오디오를 지웁니다. 기본값은 꺼짐입니다.

준비​

  1. aws CLI를 설치합니다. brew install awscli
  2. 쓸 AWS profile로 로그인합니다. aws sso login --profile <이름>
  3. 설정 → STT → AWS Transcribe에서 AWS Transcribe로 전사 허용을 켭니다.
  4. AWS profile을 고르고 S3 버킷과 리전을 적습니다. 리전은 버킷과 같아야 합니다.
  5. profile 아래 상태가 로그인 유효인지 봅니다.
상태 표시뜻
로그인 유효 — 3시간 후에 만료바로 쓸 수 있습니다.
토큰이 만료됐지만 갱신할 수 있습니다그대로 쓰면 CLI가 갱신합니다. 다시 로그인할 필요가 없습니다.
로그인이 필요합니다화면에 적힌 aws sso login 명령을 터미널에서 실행합니다.
AWS CLI가 없습니다1단계를 합니다.

전사하기​

  1. 설정 → 기록 → 회의에서 세션을 펼칩니다.
  2. 원문에서 AWS Transcribe로 전사를 누릅니다.
  3. 적은 버킷이 없으면 그 사실과 함께 <버킷> 이름으로 만들기가 뜹니다. 이름을 확인하고 누르면 퍼블릭 접근 차단, 기본 암호화, sogon/ 아래 객체를 7일 뒤 지우는 규칙을 켜고 만듭니다.
  4. 끝나면 화자 탭에서 결과를 봅니다.

이미 전사한 세션을 다시 올리면 먼저 확인을 받습니다. 결과가 새것으로 바뀌고 요금이 다시 듭니다. 화자에 지은 이름은 유지됩니다.

알아 둘 점​

  • 조각마다 올리면 화자 번호가 조각마다 달라지므로 녹음이 여러 조각이어도 하나로 합쳐 올립니다.
  • 마이크와 시스템 오디오를 함께 녹음한 세션은 시스템 오디오 트랙만 올립니다.
  • 전사 언어가 자동 감지이면 한국어로 보냅니다.
  • 다른 계정이 이미 쓰는 버킷 이름이면 이름을 바꾸라고 알립니다.
