받아쓰기

받아쓰기는 녹음 → 전사 → 교정 → 삽입 순서로 진행됩니다. 전사가 끝난 글은 녹음을 시작할 때 커서가 있던 앱과 입력칸에 들어갑니다.

녹음을 시작하는 방법​

입구동작
⌃⇧R기본은 푸시투토크입니다. 누르고 있는 동안 녹음하고 떼면 전사합니다.
⌃⇧D녹음 모드와 관계없이 한 번 눌러 시작하고 다시 눌러 끝냅니다.
메뉴 바 아이콘 오른쪽 클릭한 번 눌러 시작하고 다시 눌러 끝냅니다.
빠른 제어의 녹음 시작메뉴 바 아이콘을 왼쪽 클릭하면 나오는 창에 있습니다.
sogon://toggle다른 도구에서 켜고 끕니다. 외부 도구 연동을 봅니다.

녹음 방식은 설정 → 일반 → 녹음 → 녹음 모드에서 푸시투토크나 토글로 바꿉니다. 오른쪽 클릭 동작은 설정 → 일반 → 일반 → 메뉴 바 오른쪽 클릭에서 받아쓰기 켜고 끄기(기본), 회의 녹음 켜고 끄기, 아무 동작 없음 가운데 고릅니다.

글이 들어가는 자리​

  • 녹음을 시작한 순간의 앱과 입력칸을 기억해 두었다가 그 자리에 붙여 넣습니다.
  • 붙여 넣기는 클립보드와 ⌘V를 씁니다. 원래 클립보드 내용은 잠시 뒤 되돌립니다.
  • 붙일 곳이 없거나 붙여 넣기가 실패하면 결과가 클립보드에 남고 Voice Bar가 그 사실을 알립니다. ⌘V로 직접 붙입니다.
  • Chrome의 탭과 입력칸, iTerm2 세션(tmux 창·페인 포함)으로 복귀하려면 설정 → 일반 → 컨텍스트 복원의 두 스위치를 켜고 자동화 권한을 줍니다.
모니터가 여러 대일 때

다른 화면의 메뉴 바를 클릭하면 macOS가 그 화면의 앱을 앞으로 가져옵니다. 이때는 그 앱이 삽입 대상입니다. 원래 앱에 넣으려면 단축키를 쓰거나 그 화면의 메뉴 바에서 클릭합니다.

연달아 말하기​

앞 발화를 교정하는 동안 새로 녹음해도 됩니다. 여러 발화를 한꺼번에 처리하되 삽입은 말한 순서대로 합니다. 녹음하는 동안에는 삽입을 멈췄다가 녹음이 끝나면 이어서 넣습니다.

취소​

방법설명
⌃⇧⌫기본 취소 단축키입니다. 설정 → 일반 → 녹음 → 취소 단축키에서 바꿉니다.
Voice Bar의 취소 버튼녹음·처리 중에만 보입니다.
빠른 제어와 설정 → 상태 탭취소할 작업이 있을 때만 나타납니다.

취소는 잡아 둔 오디오와 결과를 버리고 아무것도 넣지 않습니다. 녹음 중지는 반대로 지금까지 녹음한 것을 전사해 넣습니다. esc는 취소가 아닙니다.

키 한 번으로 긴 녹음을 잃지 않도록 ⌃⇧⌫는 회의 세션만 돌고 있을 때 아무 일도 하지 않습니다. 회의 세션을 취소하려면 빠른 제어나 설정 → 상태 탭의 취소를 누르고 확인합니다.

회의 녹음 중에 받아쓰기​

⌃⇧D는 녹음 모드와 관계없이 한 번 눌러 시작하고 다시 눌러 끝내는 받아쓰기입니다. 회의 세션이 도는 동안에도 쓸 수 있고 이때 받아쓴 글은 커서로만 가고 세션 기록에는 남지 않습니다.

받아쓰기는 세션을 먼저 시작한 뒤에 붙입니다. 받아쓰기 도중에는 세션을 시작할 수 없습니다. 세션 중 빠른 제어의 녹음 중지는 세션을 멈추므로 받아쓰기만 끝내려면 ⌃⇧D를 다시 누릅니다.

녹음 소스​

설정 → 일반 → 입력에서 고릅니다.

설정기본값설명
내 마이크 캡처켜짐내 목소리를 녹음합니다.
시스템 오디오 캡처꺼짐Mac에서 재생되는 소리를 녹음합니다. 화면 녹화 권한이 필요합니다.
재생음 제거켜짐스피커 소리가 마이크로 되돌아와 두 번 전사되는 것을 줄입니다.
오디오 입력 채널자동 (다운믹스)여러 채널 오디오 장치에서 쓸 채널을 고릅니다.
전사 언어한국어자동 감지, 한국어, 영어, 일본어, 중국어, 스페인어, 프랑스어, 독일어, 포르투갈어 중에서 고릅니다.

두 소스를 함께 녹음하면 결과에 [마이크]와 [시스템 오디오] 표시가 붙습니다.

받아쓰기 서식​

설정 → 일반 → 받아쓰기 서식에서 말 사이 쉼에서 줄바꿈을 켜면 말을 멈춘 자리에 줄을 바꿉니다. 기준 쉼 길이는 0.6초이고 바꿀 수 있습니다. WhisperKit 엔진에서만 작동합니다.

Voice Bar​

녹음과 처리 중에 활성 화면 아래 가운데에 뜨는 막대입니다. 키보드 포커스를 가져가지 않으므로 대상 앱에서 계속 타이핑할 수 있습니다.

  • 설정 → 일반 → 일반 → 녹음 오버레이 표시를 끄면 뜨지 않습니다.
  • 오버레이 투명도는 불투명, 보통, 투명하게 중에서 고릅니다.
  • 빠른 제어의 눈 아이콘으로 이번 실행 동안만 숨길 수 있습니다. 메뉴 바 아이콘을 누르면 다시 나타납니다.
