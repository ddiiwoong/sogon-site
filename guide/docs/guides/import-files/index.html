파일 가져오기

녹음 앱이나 화상회의 도구로 받아 둔 파일을 Sogon으로 전사합니다. 결과는 직접 녹음한 회의와 같은 기록 항목이 되므로 회의록·전사록 만들기, 화자 붙이기, 내보내기를 그대로 씁니다.

따라 하기​

  1. 설정 → 기록을 엽니다.
  2. 파일 가져오기를 누릅니다.
    • 회의 기록이 없으면 파일 가져오기 섹션이 따로 보입니다.
    • 회의 기록이 있으면 위쪽 전환기에서 회의를 고르면 목록 맨 위에 있습니다.
  3. 파일을 고릅니다. 한 번에 20개까지 고를 수 있습니다.
  4. 파일마다 진행 줄이 뜹니다. 끝나면 회의 목록에 새 항목이 생기고 파일명 표시가 붙습니다.
  5. 항목을 펼쳐 회의록 문서 만들기 또는 전사록 문서 만들기를 누릅니다.

받는 형식​

mp3, wav, m4a, aac, aiff, caf, flac, mp4, mov

  • 영상 파일은 첫 오디오 트랙만 씁니다.
  • 원본 파일은 읽기만 하고 옮기거나 지우지 않습니다.
  • 지원하지 않거나 읽을 수 없는 파일이 섞여 있으면 그 파일만 빼고 나머지를 가져옵니다. 빠진 파일은 목록으로 알려 줍니다.
  • 21개 이상을 고르면 하나도 가져오지 않습니다.

진행과 취소​

  • 한 번에 파일 하나씩 전사하고 나머지는 대기합니다.
  • 가져오는 중에도 받아쓰기와 회의 녹음을 시작할 수 있습니다. 실시간 작업이 있으면 가져오기는 잠시 멈췄다가 이어집니다.
  • 대기 중인 파일을 취소하면 바로 빠집니다. 전사 중에 취소하면 그때까지 전사한 부분을 기록으로 남깁니다.
  • 끝난 진행 줄은 끝난 항목 지우기로 정리합니다.
