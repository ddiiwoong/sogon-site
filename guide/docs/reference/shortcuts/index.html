단축키

전역 단축키는 설정 → 일반 → 녹음에서 바꿉니다. 각 항목의 기본값으로를 누르면 아래 기본값으로 돌아갑니다.

전역 단축키​

기본값설정 이름동작기본 상태
⌃⇧R전역 단축키받아쓰기. 푸시투토크면 누르는 동안, 토글이면 눌러서 시작·다시 눌러 끝냅니다.켜짐
⌃⇧D받아쓰기 단축키녹음 모드와 관계없이 눌러서 시작하고 다시 눌러 끝내는 받아쓰기입니다. 회의 녹음 중에도 쓸 수 있습니다.켜짐
⌃⇧⌫취소 단축키진행 중인 받아쓰기를 버립니다. 회의 세션만 돌 때는 아무 일도 하지 않습니다.켜짐
⌃⇧T텍스트 입력 단축키말하지 않고 교정하는 입력창을 엽니다.켜짐
⌃⇧C선택한 글 액션 단축키선택한 글의 액션 격자를 엽니다.켜짐
⌃⇧V단축어 단축키단축어 팔레트를 엽니다.켜짐
⌃⇧S화면 영역 단축키화면 영역을 잡고 녹음합니다. 다시 누르면 제출합니다.외부 도구에서 켜야 동작
⌃⇧E화면 번역 단축키화면 영역을 잡아 그 안의 글을 읽고 번역합니다.외부 도구에서 켜야 동작
⌘C 두 번바꿀 수 없음선택한 글을 번역합니다.외부 도구에서 켜야 동작

등록된 전역 단축키는 다른 앱보다 먼저 받습니다. 다른 앱과 겹치면 그 앱에서는 해당 조합이 동작하지 않으니 겹치지 않는 조합으로 바꿉니다. ⌘C 두 번은 예외로, 복사를 막지 않고 지켜보기만 합니다.
