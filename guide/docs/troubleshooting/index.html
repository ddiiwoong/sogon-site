문제 해결

증상을 찾아 위에서부터 확인합니다. 해결되지 않으면 진단 정보를 만들어 보내 주세요.

단축키가 반응하지 않습니다​

  1. 설정 → 일반 → 권한에서 손쉬운 사용이 허용됨인지 봅니다.
  2. 방금 허용했으면 Sogon을 종료하고 다시 실행합니다.
  3. 특정 앱에서만 안 되면 그 앱의 Secure Keyboard Entry(iTerm2 등)가 켜져 있는지 봅니다. 켜져 있으면 전역 단축키가 막힙니다.
  4. 설정 → 일반 → 녹음에서 단축키가 다른 앱의 단축키와 겹치지 않는지 봅니다.
  5. ⌘C 두 번과 ⌃⇧S는 설정 → 일반 → 외부 도구에서 켜야 쓸 수 있습니다.

녹음은 되는데 글이 들어가지 않습니다​

상황조치
결과가 클립보드에만 있음튜토리얼을 시작하기로 끝내지 않았을 수 있습니다. 설정 → 일반 → 튜토리얼 → 다시 보기에서 마지막 화면의 시작하기를 누릅니다.
Voice Bar가 클립보드에 두었다고 알림붙일 입력칸이 없었거나 붙여 넣기가 막힌 곳입니다. ⌘V로 직접 붙입니다.
원격 데스크톱, 가상 머신, 비밀번호 칸붙여 넣기 합성이 닿지 않는 곳입니다. 클립보드의 결과를 직접 붙입니다.
결과가 비어 있음너무 짧게 말했거나 입력 레벨이 낮았습니다. Voice Bar의 레벨이 움직이는지 보고 다시 말합니다.

글이 엉뚱한 곳에 들어갑니다​

  • 모니터가 여러 대면 다른 화면의 메뉴 바를 클릭했을 때 받아쓴 글이 그 화면의 앱으로 들어갑니다. 단축키를 씁니다.
  • Chrome이나 iTerm2에서 탭·세션을 바꾸는 사이에 녹음했다면 설정 → 일반 → 컨텍스트 복원을 켜고 자동화 권한을 줍니다.

교정이 되지 않습니다​

  1. 설정 → LLM의 프로바이더가 없음이 아닌지 봅니다.
  2. 교정 프로바이더의 상태가 오류가 아닌지 봅니다. 오류면 키를 다시 넣습니다.
  3. 빠른 제어의 교정 사용이 켜져 있는지 봅니다.
  4. 글이 1,500자를 넘으면 교정하지 않고 원문을 넣습니다.
  5. 표준·필러 제거 모드에서는 교정이 원문의 절반 넘게 바꾸면 원문을 씁니다.

번역 창이 뜨지 않습니다​

  • 설정 → 일반 → 외부 도구에서 번역 스위치를 켰는지 봅니다.
  • 글을 실제로 선택했는지 봅니다. 선택이 없으면 ⌘C가 복사하지 않아 번역하지 않습니다.
  • ⌘C 두 번 사이 간격이 macOS 더블클릭 속도보다 길면 번역하지 않습니다.

회의 전사가 보이지 않습니다​

  • 기본은 전사하지 않고 녹음만입니다. 설정 → 기록 → 회의에서 항목을 펼쳐 전사 시작을 누릅니다.
  • 녹음하면서 전사하는 세션도 첫 결과는 최소 2분 뒤에 나옵니다.
  • 회의록 세션은 녹음 중에 전사를 보여 주지 않습니다. 전사록 세션에서 세션 전사 보기를 씁니다.

스피커로 들을 때 같은 말이 두 번 보입니다​

스피커 소리가 마이크로 되돌아와 두 트랙이 같은 말을 전사해서 생깁니다. 녹음 중 화면에는 그대로 보이고 산출물에서는 대부분 걷어냅니다. 헤드폰을 쓰면 생기지 않습니다. 자세한 한계는 알려진 문제에 있습니다.

파일 가져오기 버튼이 보이지 않습니다​

설정 → 기록을 엽니다. 회의 기록이 없으면 파일 가져오기 섹션이 따로 보이고, 회의 기록이 있으면 전환기에서 회의를 고른 뒤 목록 맨 위에서 찾습니다. 이전 판(v0.31.1 이하)에서는 회의 기록이 하나도 없으면 이 버튼이 보이지 않았습니다.
