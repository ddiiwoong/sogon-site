진단 정보 보내기

문제를 알릴 때 진단 파일을 함께 보내면 원인을 훨씬 빨리 찾습니다. 파일에는 환경 정보와 최근 로그가 들어 있고, 받아쓴 글이나 번역문 같은 본문은 들어 있지 않습니다.

만들기​

  1. 설정 → 일반 → 진단에서 디버그 로그 기록을 켭니다.
  2. 문제가 생긴 동작을 한 번 더 합니다.
  3. 같은 섹션의 진단 정보 내보내기를 누릅니다.
  4. 데스크톱에 Sogon-진단-<날짜>-<시각>.txt가 생깁니다. 이 파일을 보냅니다.
  5. 다 끝났으면 디버그 로그 기록을 다시 끕니다.

로그를 켜기 전에 일어난 일은 남아 있지 않습니다. 켠 뒤에 재현해야 합니다.

파일에 담기는 것​

담기는 것예
환경앱 버전, macOS 버전, 손쉬운 사용 신뢰 여부, 이벤트 탭 실행 여부, Secure Event Input 상태
설정 요약단축키, 녹음 모드, STT 프로바이더, 오버레이 표시
최근 로그단축키 발동, 권한 상태, 전사·교정 단계, 삽입 결과, 복원 실패 사유와 글자 수

담기지 않는 것​

  • 전사문, 교정본, 번역문, 복사한 글, 단축어 본문
  • API 키와 토큰. 실수로 섞여도 <redacted>로 가립니다.
  • 홈 폴더 경로의 사용자 이름. ~로 바꿉니다.
  • URL의 쿼리와 fragment

로그 파일​

  • 위치: ~/Library/Application Support/Sogon/Logs/. 로그 폴더 열기로 엽니다.
  • 폴더와 파일은 본인 계정만 읽을 수 있게 만듭니다.
  • sogon.log가 5MB에 닿으면 sogon.1.log로 한 번 넘기고 새로 씁니다.
  • 한 사건은 한 줄이고, 한 줄은 2,000자를 넘지 않습니다.
