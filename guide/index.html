Sogon

말하면 커서에 들어가는 macOS 받아쓰기·회의 녹음 앱

macOS 14 이상 · Apple Silicon · 음성 인식은 Mac 안에서

설치하고 시작하기단축키 한눈에 보기

키 하나로 하는 일​

⌃⇧R

말하면 커서에 들어갑니다

누른 채 말하고 떼면 녹음을 시작할 때 커서가 있던 앱과 입력칸에 교정된 글이 들어갑니다.

⌘C ⌘C

선택한 글을 바로 번역

한글은 영어로, 영어는 한글로 바꿉니다. 원문과 번역문, 실제 모델과 토큰을 한 창에서 봅니다.

⌃⇧C

선택한 글에 키 하나로 작업

교정·구조화·번역·표기 변환·메모 보내기·CLI에 묻기를 격자에서 고릅니다.

⌃⇧S

화면을 보여 주며 묻기

영역을 잡고 말하면 그림과 글이 에이전트나 채팅 입력칸에 차례로 붙습니다.

세션 녹음

회의를 녹음하고 나중에 전사

최대 3시간을 녹음하고, 끝난 뒤 회의록과 전사록을 만들고 화자를 붙입니다.

⌃⇧V

저장한 문구를 커서로

주소, 계좌번호, 템플릿을 이름으로 찾아 넣습니다. 교정을 거치지 않고 저장한 글이 그대로 들어갑니다.

처음 10분​

  1. 1설치

    DMG를 받아 Applications에 넣습니다.

  2. 2권한과 모델

    튜토리얼에서 마이크·손쉬운 사용을 허용하고 모델을 받습니다.

  3. 3첫 받아쓰기

    ⌃⇧R을 누른 채 한 문장을 말하고 뗍니다.

  4. 4LLM 연결

    교정·번역에 쓸 프로바이더와 키를 넣습니다.

기본은 Mac 안에서​

  • 음성 인식은 WhisperKit이나 MLX Audio가 Mac 안에서 처리합니다.
  • LLM 교정의 기본값은 없음입니다. 고른 프로바이더로만 글을 보냅니다.
  • 번역·화면 영역·AWS Transcribe는 직접 켜기 전까지 동작하지 않습니다.
