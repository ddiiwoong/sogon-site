Troubleshooting

Find the symptom and work from the top down. If that doesn't solve it, create diagnostics and send them.

Shortcuts do not respond​

  1. In Settings → General → Permissions, check that Accessibility shows Granted.
  2. If you just granted it, quit and relaunch Sogon.
  3. If it fails only in one app, check whether that app's Secure Keyboard Entry (iTerm2 and others) is on. When it is, it blocks global shortcuts.
  4. In Settings → General → Recording, check that the shortcut doesn't collide with another app's.
  5. ⌘C twice and ⌃⇧S work only after you turn them on in Settings → General → External Tools.

Recording works but no text is inserted​

SituationWhat to do
The result is only on the clipboardYou may not have finished the tutorial with Get started. In Settings → General → Tutorial → Show again, press Get started on the last screen.
The Voice Bar says it left the result on the clipboardThere was no field to paste into, or pasting was blocked. Paste with ⌘V.
Remote desktop, virtual machine, password fieldSynthesized paste cannot reach these. Paste the clipboard contents yourself.
The result is emptyYou spoke too briefly or the input level was low. Check that the Voice Bar level moves and try again.

Text goes to the wrong place​

  • With several displays, clicking the menu bar on another display sends the text to that display's app. Use the shortcut instead.
  • If you switched Chrome tabs or iTerm2 sessions while recording, turn on Settings → General → Context Restore and grant the Automation permission.

Correction does not happen​

  1. Check that the provider in Settings → LLM is not None.
  2. Check that the correction provider's Status is not an error. If it is, enter the key again.
  3. Check that Enable correction is on in the quick controls.
  4. Sogon inserts text longer than 1,500 characters without correcting it.
  5. In Standard and Filler Removal modes, if the correction changes more than half the original, Sogon keeps the original.

The translation window does not appear​

  • Check that the translation switch in Settings → General → External Tools is on.
  • Check that text is actually selected. With no selection, ⌘C copies nothing, so there's nothing to translate.
  • If the two ⌘C presses are further apart than the macOS double-click speed, nothing is translated.

The meeting transcription is not visible​

  • By default sessions are Record only, do not transcribe. Expand the item in Settings → History → Meetings and press Start transcription.
  • Even sessions that transcribe while recording show the first result after at least 2 minutes.
  • Minutes sessions don't show the transcription while recording. Use Show session transcript in a verbatim session.

The same speech appears twice when using speakers​

Speaker sound leaked back into the mic and both tracks transcribed it. It stays visible during recording, and Sogon removes most of it from outputs. Headphones avoid it. The limits are in Known issues.

The Import files button is missing​

Open Settings → History. With no meeting history, Sogon shows a separate Import files section; with meeting history, choose Meetings in the switcher and look at the top of the list. In earlier versions (v0.31.1 and below), the button didn't show when there was no meeting history at all.

My problem isn't listed here​

Tell us in a GitHub issue. A GitHub account is all you need; there is nothing else to sign up for.

Worth including:

  • Your macOS version and Sogon version. The Sogon version is at the bottom of the Settings window.
  • How to reproduce it. If it only happened once, say so.
  • What you expected and what happened instead.
  • A diagnostics bundle. Nothing from before you turned logging on is kept, so turn it on, reproduce it once, then export. Dictated and translated text is never in it.

You don't need to copy in any dictated text or meeting content. Issues are public, so leave out anything you cannot share.
