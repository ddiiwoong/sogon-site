Sogon

말하면 커서에 들어갑니다.

메뉴 바에서 실행되는 macOS 받아쓰기·회의 녹음 앱입니다. 음성을 전사하고 원하면 LLM으로 교정한 다음 녹음을 시작할 때 커서가 있던 자리에 넣습니다.

v0.31.6 macOS 14+ Apple Silicon Mac 안에서 음성 인식 서명·공증 완료

받아쓰기

전역 단축키를 누른 채 말하고 떼면 녹음을 시작한 순간의 앱과 입력칸에 글이 들어갑니다.

원래 있던 자리로 돌아갑니다

녹음을 시작할 때 포커스를 기억했다가 넣기 직전에 그 자리로 돌아갑니다. Kiro·VS Code 같은 편집기는 입력 포커스까지 되돌리고 자동화 권한을 주면 Chrome 탭과 입력칸, iTerm2 세션(tmux 창·페인 포함)도 되돌립니다.

이어서 말해도 순서를 지킵니다

앞 발화를 교정하는 동안 다음 녹음을 시작해도 됩니다. 전사와 교정은 동시에 진행되지만 커서에는 말한 순서대로 들어갑니다.

기본 설정으로는 Mac 밖에 보내지 않습니다

음성 인식은 MLX Audio나 WhisperKit이 Mac 안에서 처리합니다. LLM 교정의 기본값은 없음이며 클라우드 프로바이더는 직접 골랐을 때만 씁니다.

말하지 않고 교정만 받을 수 있습니다

⌃⇧T 입력창에 글을 쓰거나 붙여 넣으면 교정만 거쳐 커서 자리에 넣습니다. 창 안에서 말로 덧붙인 뒤 손으로 고쳐 제출해도 됩니다.

자주 틀리는 용어를 바로잡습니다

단어사전에 스텝 펑션 → Step Functions 같은 교정 매핑을 등록하면 LLM 없이도 전사 직후에 바뀝니다. Cloud/IT 용어 142개를 18개 주제로 나눈 사전을 가져올 수 있습니다.

잘못 말했으면 버립니다

녹음이나 전사 도중 ⌃⇧⌫를 누르면 아무것도 넣지 않고 끝냅니다. 다른 앱이 esc를 그대로 받도록 esc는 취소에 쓰지 않습니다.

선택한 글과 화면

이미 화면에 있는 글도 키 하나로 번역하거나 다시 씁니다.

⌘C 두 번으로 번역

글을 선택하고 ⌘C를 빠르게 두 번 누르면 한글은 영어로, 영어는 한글로 번역해 원문 옆에 보여 줍니다. 기본 엔진인 Apple Translation은 이 Mac 안에서 번역합니다. 모든 ⌘C를 지켜보므로 기본으로 꺼져 있습니다.

⌃⇧C 액션 격자

선택한 글에 교정·구조화·번역·대소문자 변환·메모 보내기·CLI에 묻기를 키 하나로 적용합니다. 다시 쓴 결과는 먼저 보여 주고 덮을지 묻습니다.

⌃⇧V 단축어

계좌번호, 주소, 영문 서명처럼 매번 같은 글을 저장해 두고 이름으로 찾아 넣습니다. 저장한 글은 교정을 거치지 않습니다.

⌃⇧S 화면을 보여 주며 묻기

화면 일부를 잡고 질문을 말하면 그림과 교정된 글을 에이전트나 채팅 입력칸에 차례로 붙입니다. 이 기능도 기본으로 꺼져 있습니다.

회의 녹음

받아쓰기와 별도로 최대 3시간까지 녹음하는 세션이 있습니다. 녹음을 먼저 하고 회의가 끝난 뒤 전사하는 것이 기본입니다.

전사는 회의가 끝난 뒤에

오디오를 남겨 두므로 전사 때문에 회의 중에 Mac이 느려지지 않습니다. 더 나은 모델이 나오면 같은 오디오로 다시 전사할 수 있습니다.

회의록과 연속 전사록

요약·결정 사항·액션 아이템으로 정리한 회의록과 요약 없이 이어 붙인 전사록을 한 세션에서 각각 만듭니다. .txt·.md로 내보내거나 Apple 메모로 보냅니다.

마이크와 시스템 오디오를 따로

내 목소리와 화상회의 상대의 소리를 다른 트랙으로 녹음합니다. 두 트랙이 모두 잡히면 전사문에 [마이크]와 [시스템 오디오] 표시가 붙습니다.

누가 말했는지 붙입니다

macOS 26 이상에서는 Mac 안에서 화자를 나누고 AWS Transcribe를 켜면 최대 30명까지 구분합니다. 화자마다 이름을 지을 수 있습니다.

이미 있는 녹음도 전사합니다

mp3, m4a, wav, mp4, mov 등 9가지 형식의 파일을 한 번에 20개까지 가져와 회의 세션과 같은 방식으로 전사합니다.

녹음하면서 받아쓰기

세션을 녹음하는 동안 ⌃⇧D로 받아쓰기를 붙이면 회의는 계속 녹음되고 받아쓴 글만 커서로 들어갑니다.

설치

공개 릴리스입니다. 로그인이나 별도 도구 없이 바로 내려받습니다.

v0.31.6 릴리스에서 Sogon.dmg를 받아 열고 Sogon.app을 /Applications로 옮깁니다. Developer ID로 서명하고 Apple 공증을 마친 빌드라 Gatekeeper 경고 없이 실행됩니다. 권한 설정과 첫 받아쓰기는 사용 설명서에 순서대로 적어 두었습니다.

Homebrew를 쓴다면 brew install --cask ddiiwoong/sogon/sogon 한 줄로 받습니다. 설치한 뒤 업데이트는 Sogon이 직접 받으므로 brew upgrade는 필요하지 않습니다.

말하지 않고 교정⌃⇧T

저장한 문구 넣기⌃⇧V
회의 녹음메뉴 바 아이콘 → 녹음 시작 (전사는 나중에)
취소⌃⇧⌫
결과 확인설정 → 기록
회의를 녹음하는 동안 빠른 제어의 녹음 중지는 세션을 멈춥니다. 받아쓰기만 끝내려면 ⌃⇧D를 다시 누릅니다. 받아쓰기 도중에는 세션을 시작할 수 없으므로 세션을 먼저 시작합니다.
