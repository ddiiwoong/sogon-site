Sogon

말하면 커서에 들어갑니다.

메뉴 바에 상주하는 macOS 받아쓰기 앱입니다. 전역 단축키를 누른 채 말하면 전사하고, 원하면 LLM으로 다듬어 녹음을 시작할 때 커서가 있던 자리에 넣습니다.

v0.31.6 macOS 14+ Apple Silicon

받아쓰기

커서가 있던 자리

녹음을 시작할 때 포커스를 기억했다가 넣기 직전에 그 자리로 돌아갑니다. Kiro·VS Code 같은 편집기는 입력 포커스까지 되돌립니다. 자동화 권한을 주면 Chrome 탭과 입력칸, iTerm2 세션도 찾아갑니다. tmux 창과 페인까지 봅니다.

말한 순서

앞 발화를 다듬는 동안 다음 녹음을 시작해도 됩니다. 전사와 교정은 겹쳐 돌지만 커서에는 말한 순서대로 들어갑니다.

기본값은 로컬

음성 인식은 MLX Audio나 WhisperKit이 이 Mac 안에서 합니다. LLM 교정의 기본값은 없음이고, 클라우드 프로바이더는 직접 고를 때만 씁니다.

말 없이 교정만

⌃⇧T 창에 쓰거나 붙여 넣으면 교정만 거쳐 커서로 들어갑니다. 창 안에서 말로 덧붙이고 손으로 고쳐 제출해도 됩니다.

단어사전

스텝 펑션 → Step Functions 같은 매핑을 등록하면 LLM을 거치지 않고 전사 직후에 바뀝니다. Cloud·IT 용어 142개를 18개 주제로 나눠 둔 사전을 가져올 수 있습니다.

취소

녹음이나 전사 중에 ⌃⇧⌫를 누르면 아무것도 넣지 않고 끝납니다. esc는 취소에 쓰지 않습니다. 다른 앱이 그대로 받아야 하니까요.

선택한 글과 화면

⌘C 두 번, 번역

글을 선택하고 ⌘C를 빠르게 두 번. 한글은 영어로, 영어는 한글로 바꿔 원문 옆에 보여 줍니다. 기본 엔진인 Apple Translation은 이 Mac 안에서 돕니다. 모든 ⌘C를 지켜봐야 해서 기본으로 꺼져 있습니다.

⌃⇧C 액션 격자

선택한 글에 교정·구조화·번역·대소문자 변환·메모 보내기·CLI에 묻기를 키 하나로 적용합니다. 다시 쓴 결과는 덮기 전에 보여 줍니다.

⌃⇧V 단축어

계좌번호, 주소, 영문 서명처럼 매번 같은 글을 저장해 두고 이름으로 찾아 넣습니다. 저장한 글은 교정을 거치지 않고 그대로 들어갑니다.

⌃⇧S 화면 보여 주며 묻기

화면 일부를 잡고 질문을 말하면 그림과 교정된 글을 에이전트나 채팅 입력칸에 차례로 붙입니다. 기본으로 꺼져 있습니다.

회의 녹음

받아쓰기와 별개로, 한 세션에 최대 3시간까지 녹음합니다. 녹음을 먼저 하고 회의가 끝난 뒤에 전사하는 것이 기본입니다.

전사는 나중에

오디오를 남겨 두니 전사 때문에 회의 중에 Mac이 느려지지 않습니다. 더 나은 모델이 나오면 같은 오디오로 다시 돌릴 수 있습니다.

회의록과 전사록

요약·결정 사항·액션 아이템으로 정리한 회의록, 그리고 요약 없이 이어 붙인 전사록을 한 세션에서 각각 만듭니다. .txt·.md로 내보내거나 Apple 메모로 보냅니다.

마이크와 시스템 오디오

내 목소리와 화상회의 상대 소리를 다른 트랙에 담습니다. 둘 다 잡히면 전사문에 [마이크], [시스템 오디오] 표시가 붙습니다.

화자 구분

macOS 26 이상에서는 Mac 안에서 나눕니다. AWS Transcribe를 켜면 최대 30명까지 구분하고, 화자마다 이름을 지을 수 있습니다.

이미 있는 녹음

mp3·m4a·wav·mp4·mov 등 9가지 형식을 한 번에 20개까지 가져와 회의 세션과 같은 방식으로 전사합니다.

녹음하면서 받아쓰기

세션이 돌아가는 중에 ⌃⇧D로 받아쓰기를 붙이면, 회의는 계속 녹음되고 받아쓴 글만 커서로 들어갑니다.

설치

공개 릴리스라 로그인 없이 받습니다. v0.31.6 릴리스에서 Sogon.dmg를 받아 열고 Sogon.app을 /Applications로 옮깁니다. Developer ID로 서명하고 Apple 공증을 마친 빌드라 Gatekeeper 경고가 뜨지 않습니다. 권한 설정과 첫 받아쓰기는 사용 설명서에 순서대로 적어 두었습니다.

Homebrew를 쓴다면 brew install --cask ddiiwoong/tap/sogon 한 줄입니다. 그다음부터는 Sogon이 직접 업데이트를 받으므로 brew upgrade는 필요하지 않습니다.

하려는 일방법
받아쓰기⌃⇧R을 누른 채 말하고 뗍니다
말하지 않고 교정⌃⇧T
선택한 글 번역⌘C 두 번 (설정에서 켠 뒤)
선택한 글에 작업⌃⇧C
저장한 문구 넣기⌃⇧V
회의 녹음메뉴 바 아이콘 → 녹음 시작 (전사는 나중에)
취소⌃⇧⌫
결과 확인설정 → 기록
회의를 녹음하는 동안 빠른 제어의 녹음 중지는 세션을 멈춥니다. 받아쓰기만 끝내려면 ⌃⇧D를 다시 누릅니다. 받아쓰기 도중에는 세션을 시작할 수 없으니 세션을 먼저 켜 두세요.
